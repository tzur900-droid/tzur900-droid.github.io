אפליקציית אנדרואיד בעברית בסגנון סירי. אתה מדבר, היא מבינה ומבצעת.

אפשר גם להקליד פקודה בשדה הטקסט.

## איך בונים את ה-APK

### דרך א. Android Studio במחשב (הכי פשוט)

1. מתקינים Android Studio.
2. File ← Open ← בוחרים את תיקיית הפרויקט הזו.
3. ממתינים לסיום ה-Gradle sync.
4. Build ← Build Bundle(s) / APK(s) ← Build APK(s).
5. הקובץ נוצר ב-`app/build/outputs/apk/debug/app-debug.apk`.
6. מעבירים אותו לטלפון ופותחים אותו.

אפשר גם לחבר את הטלפון בכבל, להפעיל ניפוי באגי USB וללחוץ Run.

### דרך ב. GitHub, בלי להתקין כלום

1. פותחים repository חדש ב-GitHub ומעלים אליו את כל תוכן התיקייה, כולל התיקייה המוסתרת `.github`.
2. נכנסים ללשונית Actions, בוחרים Build APK ולוחצים Run workflow.
3. כשהריצה מסתיימת, מורידים את `ozer-kooli-apk` מאזור Artifacts ומחלצים את `app-debug.apk`.

העלאת תיקייה שלמה עובדת מדפדפן במחשב. מהטלפון זה קשה.

## התקנה בסמסונג

פותחים את קובץ ה-APK. אם הטלפון חוסם, מאשרים "התקנה ממקורות לא מוכרים" עבור האפליקציה שממנה פתחת אותו (Files, Chrome וכדומה).

בהפעלה הראשונה האפליקציה מבקשת הרשאות, ואתה מאשר:

- מיקרופון, להקשבה.
- אנשי קשר, כדי למצוא מספרים לפי שם.
- חיוג, כדי להתקשר ישירות. אם תסרב, החייגן ייפתח עם המספר ותלחץ על חיוג בעצמך.

## להפעיל בלחיצה על הכפתור הצדדי

הגדרות ← תכונות מתקדמות ← מקש צד ← לחיצה כפולה ← פתח אפליקציה ← עוזר קולי.

האפליקציה מתחילה להקשיב מיד כשהיא נפתחת. אפשר לכבות את זה בתיבת הסימון שבתחתית המסך.

## מגבלות

- אין מילת הפעלה כמו "היי סירי". צריך לפתוח את האפליקציה או ללחוץ על המיקרופון. אנדרואיד לא מאפשר לאפליקציה רגילה להאזין כל הזמן ברקע.
- זיהוי הדיבור משתמש בשירות של גוגל ודורש אינטרנט.
- הקראה בעברית דורשת קול עברי מותקן: הגדרות ← ניהול כללי ← המרת טקסט לדיבור.
- הודעת SMS ואירוע ביומן נפתחים מוכנים, ואתה לוחץ שלח או שמור. זו בחירה מכוונת כדי שלא יישלח דבר בטעות.
- אנדרואיד לא מאפשר לאפליקציה להדליק או לכבות WiFi ובלוטוס. היא פותחת את מסך ההגדרות.
- הקוד לא נבדק על מכשיר אמיתי. אם משהו לא עובד, שלח לי את הודעת השגיאה ואתקן.
